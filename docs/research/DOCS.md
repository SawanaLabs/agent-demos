# Research Knowledge Protocol

本目录保存支持产品和技术选择的研究。先读 [研究目录](./index.md)，再进入对应主题。

## Evidence and Freshness

- 记录研究日期、原始问题和可访问的来源；优先引用官方文档与评测发布方。
- 区分来源事实、研究推断和本项目实测结果。公开评测不能直接替代本项目验收。
- 对价格、模型和评测数据保留档位、单位及版本信息；再次用于决策前核对来源。

## Scope

- 按主题在目录中分组，当前文档直接放在本目录，积累后再拆分子目录。
- 研究结论不代表已经实施；落实后的运行约定放入对应业务域文档。
- 新增或移动研究时同步更新目录，保留来源和比较限制。
